# Pelican Pedal · 鹈鹕骑行

A pelican rides a bicycle along an endless coastal road.

**Play:** https://mushengziyue.github.io/pelican-pedal/

Single-file HTML5 canvas game — no build, no dependencies.

- `SPACE` / tap — hop (hold for height, tap again mid-air to flap)
- `B` — take off when the beak meter is full
- `P` — pause · `M` — mute
